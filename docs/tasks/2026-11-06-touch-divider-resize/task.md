# 2026-11-06-touch-divider-resize

Task ID: `2026-11-06-touch-divider-resize`
Type: `bug`

## 背景与问题

鼠标按住分隔条可以连续调整面板比例。用手指做相同操作时，浏览器会在抬起前发出 `pointercancel`，提前结束拖拽。在使用仓库组件的隔离测试页中，Chromium 触屏模拟在横竖两个方向均只跟随了 72px 手势的前 18px。

## 目标

触屏与鼠标共用现有操作方式。按住分隔条后移动时，比例持续跟随同轴位移；松开时，按现有规则结束并保存。

## 范围

Framework Client 的分隔条拖拽命中区及对应验证。修复手势起点的浏览器行为，沿用现有尺寸计算、遮罩、取消清理和比例保存链路。

## 非目标

新增手势、改变分隔条外观和命中尺寸、改动标签拖放、Kit 布局或 Plugin。

## 验收标准

- 在相同初始布局上，触屏与鼠标沿横轴、纵轴各拖动相同距离，分隔条在松开前持续跟随并达到相同位置。
- 指针移入面板区域后可继续拖动。松开后比例按现有流程保存，拖拽遮罩解除。
- 触屏从面板内容区起手时仍可滚动。桌面鼠标拖拽通过回归验证，明确记录实际覆盖的设备和浏览器。

## 约束

Web 宿主内验证，保留原有鼠标交互作为验收基准。按 Framework 功能单元运行针对性验证。

## 需求变更

用户明确要求对齐触屏和鼠标操作，并确认开始推进。范围聚焦分隔条在手指松开前的拖动中断。

用户确认在当前 `main` 分支修复，并在验证后提交一个本地 commit。
