# 修复 Agent Guard 历史监控不可用与大数据崩溃

Task ID: `2026-08-06-history-dashboard-crash`
Type: `bug`

## 背景与问题

Agent Guard 的历史监控界面存在两个用户可见回归：网络流量历史显示为不可用；切换到模型用量时，数据量较大会导致面板崩溃。两者共同使历史趋势功能无法可靠使用。

## 目标

恢复网络流量历史的正常查询与展示，并确保模型用量在大量历史数据下仍能稳定加载和交互，不触发面板崩溃。

## 范围

本 Task 仅覆盖 Agent Guard Kit 的历史查询、历史数据传输/聚合和面板渲染路径，以及能够复现这两个缺陷的自动化测试。

## 非目标

不改变网络采集口径、模型用量解析语义、历史保留策略或异常熔断策略；不修改其他 Kit 或 Harbors 共享框架。

## 验收标准

- 有网络历史数据或有效覆盖信息时，网络流量视图可以完成查询并正常展示，不进入“暂不可用”状态。
- 切换到模型用量时，即使底层历史数据量很大，面板也不会崩溃且仍能展示正确的汇总与趋势。
- 网络流量与模型用量的现有单位、来源和缺口语义保持不变。
- 新增回归测试覆盖网络历史不可用和模型用量大数据场景。
- Agent Guard 的聚焦构建、测试和浏览器验收通过。

## 约束

改动必须限制在 `kits/agent-guard` 和本 Task 的三份正式档案内；共享行为优先通过 Web 预览验证。历史数据处理必须保持有界，避免把未压缩的大规模点集直接交给浏览器渲染。

## 需求变更

本 Task 未发生需求变更。
