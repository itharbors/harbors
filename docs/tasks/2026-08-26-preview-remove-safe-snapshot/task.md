# Preview 快照清理与独立网页视口

Task ID: `2026-08-26-preview-remove-safe-snapshot`
Type: `refactor`

## 背景与问题

Harness Preview 当前为 HTTP(S) 网页同时启动受限代理和安全快照抓取，并在面板工具栏中提供“代理网页 / 安全快照 / 重试快照”切换。用户确认安全快照没有保留价值，要求完整删除该能力，而不是仅隐藏入口。现有实现因此存在多余的并发抓取、状态字段、消息请求、HTML 清洗与 `srcdoc` 渲染，以及持续占据预览区域的模式工具栏。

同时，当前网页 iframe 尺寸始终跟随 Preview Panel，无法用一个较小 Panel 观察和操作桌面网页视口。用户要求网页逻辑视口与 Panel 尺寸解耦，可设置不同宽高；当固定尺寸 iframe 超出 Panel 时，通过类似触控板的手势控制虚拟鼠标并平移视口，在有限区域内操作正常尺寸网页。

## 目标

1. 从 Harness Preview 插件完整移除网页安全快照能力及其用户界面。
2. HTTP(S) 网页只通过现有受限代理预览，保留代理 sandbox、会话校验与关闭生命周期。
3. 删除不再可达的快照抓取、状态、消息协议、样式、构建产物和测试，避免留下兼容分支或死代码。
4. 本地 HTML 文件按普通文本代码预览，不再通过网页 `srcdoc` 执行或渲染。
5. 网页逻辑视口宽高独立于 Preview Panel，可设置为与 Panel 不同的尺寸。
6. 为超出 Panel 的网页视口提供虚拟鼠标交互：滑动移动、轻点左键、长按右键，并通过自动平移让虚拟指针与目标区域保持可见。
7. 提供“直接交互”和“模拟鼠标”两种模式并允许随时切换；直接交互使用真实鼠标操作网页，模拟鼠标模式由手势层接管。

## 范围

- `kits/harness/plugins/preview/main/**` 中 `fetchWebPage`、网页快照响应字段及本地 HTML 快照分支。
- `kits/harness/plugins/preview/main/src/proxy/**` 中与受限代理页面桥接、视口尺寸和虚拟指针命令有关的最小实现。
- `kits/harness/plugins/preview/panel.preview/**` 中快照状态、模式切换、重试入口、快照 HTML 清洗和 `srcdoc` iframe。
- `kits/harness/plugins/preview/panel.preview/**` 中网页视口尺寸设置、裁剪/平移画布、触控板手势和虚拟指针反馈。
- `kits/harness/plugins/preview/package.json` 中 `fetchWebPage` 消息声明；仅在确认无其他用途时清理依赖。
- Preview 插件的针对性测试、构建产物与本 Task 档案。

## 非目标

- 不删除或放宽现有受限网页代理、SSRF 防护、代理 iframe sandbox、代理 URL 校验和代理会话回收。
- 不修改 Harness 其他 Plugin、Framework Client、Server Framework 或通用消息系统。
- 不为 HTTPS 宿主新增远程代理方案；当前本地代理的 mixed-content 限制保持不变。
- 不承诺触发浏览器原生右键菜单，也不绕过目标网页对 `isTrusted` 合成事件的拒绝；长按只要求向代理页面分发可验证的 `contextmenu` 语义。
- 不在本 Task 中提供跨重启的视口尺寸偏好持久化；尺寸至少在当前 Preview 页签生命周期内保持稳定。
- 不把真实触摸事件直接透传给目标页面；启用虚拟鼠标模式时由 Preview 手势层接管交互。
- 不把交互模式切换实现为重新打开代理或刷新页面；切换应保持当前网页、滚动位置和已设置视口尺寸。
- 不回写或改写历史 Task 文档；旧文档继续作为当时实现记录。
- 不执行 push、创建 PR 或整合到本地 `main`；交付动作需要后续单独授权。

## 验收标准

1. Preview 面板不再展示“安全快照”“重试快照”“代理网页”等模式工具栏及快照状态文案；新增尺寸与交互入口不复用旧模式工具栏语义。
2. 打开 HTTP(S) 链接时只发起 `openProxyPage`，不再调用 `fetchWebPage`，代理成功后直接显示受限 iframe。
3. Plugin manifest、主进程与面板状态中不存在 `fetchWebPage`、`snapshotHtml`、`snapshotError`、`snapshotLoading`、快照模式或同义兼容字段。
4. 不再存在安全快照专用网页抓取实现、HTML `srcdoc` 渲染、切换/重试事件及相应样式和测试。
5. 本地 `.html` / `.htm` 文件作为代码文本预览，HTML 内容被转义，不执行脚本。
6. 代理加载、失败、关闭标签和切换会话行为保持正确；代理 iframe 继续仅授予既有受限 sandbox 能力。
7. Preview 插件针对性测试、类型检查/构建、`git diff --check` 通过，并在唯一 Web 宿主中完成浏览器验收。
8. 业务代码变更严格限制在 `kits/harness/plugins/preview/**`，符合 Kit 专属 Plugin 边界。
9. 用户可以为每个网页 Preview 页签设置逻辑视口宽度和高度；调整 Panel 大小时，已设置的网页视口尺寸不会被自动改写。
10. iframe 按设置后的逻辑尺寸渲染，并由 Panel 内的裁剪视窗承载；尺寸大于 Panel 时不挤压外部布局，也不扩大 Panel。
11. 启用虚拟鼠标后，单指/主指针滑动按位移控制可见虚拟光标，轻点触发目标位置的左键点击，达到长按阈值时向目标位置发送右键 `contextmenu` 交互，且一次手势不会同时触发左键和右键。
12. 虚拟光标移动至当前裁剪视窗边缘时，预览画布在可用范围内自动平移，使光标及其目标区域保持可见；平移不得越过网页逻辑视口边界。
13. Panel 与代理 iframe 之间的控制消息必须绑定当前代理会话和预期来源，校验消息类型、坐标与尺寸范围，不引入任意脚本执行或跨会话控制通道。
14. 键盘用户可以访问尺寸设置并退出虚拟鼠标模式；`prefers-reduced-motion` 下不依赖连续动画完成定位，虚拟光标状态不只依赖颜色表达。
15. 浏览器验收至少覆盖：视口大于 Panel、视口小于 Panel、Panel 动态缩放、滑动移动、轻点链接/按钮、长按页面自定义右键处理、边缘自动平移和代理失败状态。
16. 用户可以在“直接交互”和“模拟鼠标”之间显式切换；当前模式有清晰的文字、选中状态和辅助技术语义，不能只靠颜色区分。
17. 直接交互模式不显示也不拦截虚拟鼠标手势层，真实鼠标可以按现有代理限制直接操作 iframe；模拟鼠标模式启用手势层并阻止同一手势重复透传给 iframe。
18. 两种模式共享同一代理 iframe 与逻辑视口；来回切换不重载页面、不新建代理会话、不重置页面滚动位置、画布平移位置或用户设置的宽高。

## 约束

- Harbors 仅支持 Web 宿主；共享可见行为必须通过 Web 浏览器验收。
- 完整清理以运行时和协议不可达为准，不能只用 CSS 隐藏按钮。
- 保留代理现有安全限制；删除快照不等于允许目标网页获得同源、表单、弹窗、下载或顶层导航权限。
- 网页尺寸和虚拟鼠标控制必须建立在受限代理内，不允许为了访问 iframe DOM 而给 iframe 增加 `allow-same-origin`。
- 合成鼠标事件属于能力受限的代理交互：测试必须区分普通 DOM 交互成功与目标站点拒绝非可信事件，不能伪装成完整真实鼠标兼容。
- 保留当前工作区已有 Tips Task 文件；不得 stash、reset、清理或覆盖用户文件。
- `status.json` 只通过 Task CLI 修改。

## 决策上下文与处置

### Decision Context

- 用户在真实 Preview 页面确认该工具栏和快照能力没有必要，并进一步明确要求“删除快照功能，完整清理掉”。该决定覆盖此前“保留快照作为安全回退”的产品方向。
- 用户随后追加目标：网页尺寸与 Panel 尺寸解耦，并在超大 iframe 被裁剪时用滑动、轻点和长按模拟鼠标操作正常尺寸网页。
- 已查询批准决策记忆，未找到要求保留 Harness Preview 安全快照的 decision、constraint、lesson 或 rule；索引 freshness 为 `partial`，有 1 个失败文件，因此不能把空结果解释为完整知识库证明。
- 仓库历史 Task `2026-08-21-preview-safe-web` 记录了快照与代理并存的当时实现事实，不是阻止当前产品方向调整的 ADR。
- owner：当前主 Agent，负责 Task 状态、实际 diff、边界检查和验证证据。
- reviewer：执行计划中的独立审查角色，负责确认无残留协议、死代码或代理安全回归。
- approver：当前用户，负责工作环境和后续交付选择。

### 逐条处置与分工

- **采用用户新决定**：完整移除安全快照，不保留隐藏开关或兼容入口。
- **保留安全边界**：受限代理及其 SSRF、sandbox、URL 校验和生命周期不变。
- **收敛本地 HTML 行为**：复用已有文本文件预览，避免为本地 HTML 保留快照型 `srcdoc` 通道。
- **采用独立视口**：每个网页页签持有独立逻辑宽高，Panel 只作为裁剪和控制表面。
- **采用虚拟鼠标语义**：滑动移动虚拟光标，轻点左键，长按分发页面级右键语义；边缘自动平移连接超大视口与有限 Panel。
- **提供模式切换**：直接交互保留真实鼠标操作，模拟鼠标由手势层接管；两种模式复用同一 iframe，不以页面重载换取状态切换。
- **维持跨源隔离**：通过代理页面内受约束的桥接处理虚拟指针命令，不增加 iframe 同源权限。
- **边界限制**：所有业务实现均在 Harness Preview Plugin 文件夹内完成；若发现必须修改外部路径，停止并先向用户确认。

### 过程关联

- 消息声明与主进程方法清理映射到 `package.json`、`main/src/index.ts` 和快照抓取模块。
- 状态、渲染、交互和样式清理映射到 `panel.preview/src/**`。
- 视口尺寸、平移和手势状态映射到 Panel；页面目标命中和受限合成事件映射到 Proxy 页面桥接，两侧通过校验后的会话消息连接。
- 测试与构建产物同步清理映射到 Preview 插件的针对性验证。

## 需求变更

- 初始页面反馈认为快照工具栏可能没有必要；进一步确认后，需求从“压缩工具栏”升级为“完整删除安全快照功能”。
- 删除后不提供快照回退：代理不可用时直接显示代理错误，本地 HTML 改为代码文本预览。
- 新增独立网页视口与虚拟鼠标目标：设置尺寸后 iframe 可大于 Panel，通过滑动、轻点、长按和边缘自动平移完成受限交互。
- 长按“右键”按页面 `contextmenu` 语义验收；浏览器原生菜单和拒绝合成事件的网站明确不在兼容承诺内。
- 新增直接交互/模拟鼠标模式切换；按用户表述，将“实际大小”解释为真实鼠标直接交互，且切换不得刷新网页或丢失视口状态。
