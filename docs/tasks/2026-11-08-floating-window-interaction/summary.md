# 浮窗交互与窗口打开

## 当前结果

Web 浮窗支持标题栏拖动和左右下角缩放。Harness 已注册的五个面板菜单优先在当前工作台打开浮窗；标题栏可关闭浮窗或在新窗口打开，后者在目标面板挂载成功后关闭原浮窗。最小化按钮及底部恢复条已移除。

## 验证与限制

- Client、Server 和目标 Kit 插件的定向测试及构建通过；48381 的桌面浏览器验证了五个菜单、关闭后重开和设置页转到新窗口，390px 视口验证了设置浮窗。
- 未在真实手机或两个设备同时操作；未保存的页面输入不会自动转移到新窗口。
- 其他 Kit 或第三方菜单如果没有声明本地面板动作，仍使用原打开方式；插件 SDK 的原有 `openPanel` 契约保留。
- 新窗口未打开的副本会过期回收；若窗口入口已经标记打开，之后双方同时失联或清理请求失败，服务端实例仍可能残留。
- 旧最小化状态保留兼容并显示为浮窗；拖拽停靠和真实触屏未在本轮全面复验。

## 分类

- blocking：真实手机与双设备验收、未声明本地动作的插件是否需要统一。
- non_blocking：异常失联时窗口实例可能残留；缩放角尚无键盘等价操作。
- decision_candidates：无。
- follow_up：按需要完善通用插件入口和跨设备生命周期。
