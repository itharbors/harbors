# 2026-11-08-floating-window-interaction

## Summary

修复 Web 工作台浮动窗口无法拖动和缩放的问题。保持现有布局、停靠与浮窗内容状态；标题栏拖动窗口，左右下角提供可见的缩放手柄，缩放受最小尺寸和工作台边界约束。最小化恢复及其他浮窗操作后位置尺寸保留，不重载面板。验证客户端定向测试和 48381 实际浏览器拖动、左右角缩放及关闭操作。沿用用户已选择的当前工作区，不提交或发布。

用户要求顶部菜单中的面板默认在当前工作台浮动显示；浮窗标题栏提供在新窗口打开及关闭，移除最小化按钮和底部恢复条；关闭后可由菜单重新打开。审查并清理不再需要的代码，保留现有会话、其他设备窗口和旧状态的必要兼容。新窗口及原浮窗如何共存，按用户答复确定；未保存的页面输入不能假定会跨 iframe 迁移。
