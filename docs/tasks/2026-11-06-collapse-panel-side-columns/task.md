# 双击 Tab 收起侧栏

Task ID: `2026-11-06-collapse-panel-side-columns`
Type: `feature`

## 背景与问题

固定的侧栏在窄屏上占用主工作区。用户希望双击 Panel Tab 名称，将相关一栏收起，以便临时腾出空间。

## 目标

在左或右侧栏双击同一个 Tab 名称，收起该侧整列，包括同列上下分布的面板。侧边保留可点击的展开入口。

## 范围

Framework Client 的 Panel Group 手势、工作区侧栏呈现与恢复。收起状态仅在当前页面保留。展开复用当前面板实例和列尺寸。

## 非目标

自动按视口收起，改变 Kit 默认布局、Panel 生命周期或服务端协议，跨刷新持久化收起状态。

## 验收标准

- 桌面双击与触屏双点均可收起侧边整列。右侧上下两个组一起收起，中心列仍可用。
- 侧边入口单击或键盘激活可展开，恢复原有宽度和 iframe，收起过程不覆盖保存尺寸。
- 单击切换、Tab 拖拽、分隔条拖动及旋转往返保持可用。在窄视口侧边入口可见。

## 约束

实现和验收在 Web 宿主。遵循 [布局与窗口模型](../../architecture/layout-model.md#tab-拖放) 和 [测试指南](../../guides/testing.md)。

## 需求变更

用户认可先做整列收起和侧边展开入口供审核。作为第二项在当前 `main` 单独提交。
