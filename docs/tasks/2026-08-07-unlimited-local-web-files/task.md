# 取消本机 Web 文件大小上限

Task ID: `2026-08-07-unlimited-local-web-files`
Type: `feature`

## 背景与问题

本机 Web 文件打开功能最初设置了 2 GiB 应用层上限。用户明确：通过 loopback Web 选择的是运行 Harbors 同机上的本地文件，不应由 Harbors 预先限制文件大小。

## 目标

取消 localhost/loopback Web 打开本机文件时的默认应用层大小上限，同时保留流式暂存、远程拒绝和失败清理行为。

## 范围

- `LocalWebFileStore` 默认不配置最大字节数。
- 默认路径不因 `Content-Length` 或累计流量超过 2 GiB 而拒绝。
- 保留可选的显式上限能力及其残片清理测试。
- 更新既有本机 Web 文件设计文档和回归测试。

## 非目标

- 改为浏览器随机读取或避免完整暂存副本。
- 允许非 loopback Web 使用本机文件端点。
- 改变 Electron 直接打开绝对路径的行为。

## 验收标准

- 默认本机 Web 文件存储不再返回 `LOCAL_FILE_TOO_LARGE`。
- 超过原 2 GiB 阈值的声明长度不触发默认应用层拒绝。
- 显式配置上限时仍能中止超限流并删除部分文件。
- Server 完整测试与仓库门禁通过。

## 约束

- Web 仍会完整流式复制用户选择的文件，实际可用性受磁盘空间、文件系统和运行环境约束。
- 上传失败或中断必须清理 `.part` 和本次上传目录。
- 会话与 Server 生命周期清理规则保持不变。

## 需求变更

PR #63 合并后，用户明确取消此前 2 GiB 默认上限；本 Task 作为独立后续变更，不修改已合并 Task 的历史状态。
