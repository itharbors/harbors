# 移动端键盘视口适配

外层工作台同步可见视口的高度及输入焦点期间的偏移，并识别 Shadow DOM 内的面板 iframe；触屏设备的对话输入框字号调整为 16px，减少 iOS 聚焦自动放大的可能。

验证：客户端入口测试 13 项通过，客户端类型检查和构建通过，Chat 插件样式及插件构建通过。浏览器在 48381 端口打开 Harness，确认工作台可加载、对话输入框可聚焦，且已加载新的外层视口设置；焦点路径为 CE-PANEL / IFRAME。

通过本机 HTTP 读取 48381 对话面板的 CSS，确认服务已提供触屏 16px 输入框规则。

未完成：iPhone 和 iPad 的实际软键盘弹出、收起、缩放以及动画稳定性需真机验收。阶段保持 blocked，待真机确认。

决策增量：无。此变更是局部移动端兼容修复，沿用 Web 宿主和插件隔离边界。
