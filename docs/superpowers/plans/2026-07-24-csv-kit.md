# CSV Kit Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Build an independently publishable, Chinese, read-only CSV workbench that matches the SQLite Kit's file-selection, explorer, paged data, filtering, sorting, cell-detail, schema, and export experience.

**Architecture:** `csv-core` owns read-only file access, streaming CSV decoding, and a session-scoped temporary SQLite index; `csv-explorer` owns connection/configuration and field navigation; `csv-data` owns paged data and schema panels. Browser panels exchange only serializable contracts from `@itharbors/csv-contracts`, and never receive the full dataset.

**Tech Stack:** TypeScript 5.7, Node.js 22.18, `csv-parse` 7.0.1, `iconv-lite` 0.7.3, `better-sqlite3` 11.x, native DOM/CSS, Vitest/jsdom, Harbors plugin and Kit CLI.

## Global Constraints

- Source files are always read-only; export writes a new UTF-8 BOM CSV and refuses an existing destination.
- Supported encodings are UTF-8 (with or without BOM) and GB18030; supported delimiters are comma, tab, and semicolon.
- The parser must preserve field text, quoted newlines, escaped quotes, empty strings, leading zeroes, and unsafe integers without type coercion.
- Default page size is 50; allowed page sizes are 25, 50, 100, and 250.
- Maximum source size is 2 GiB, maximum decoded field size is 16 MiB, and maximum column count is 10,000.
- Temporary indexes live below an owned random directory in the OS temporary directory and are removed on failure, cancel, close, unload, and expired-owner cleanup.
- Queries support full-row search, multiple `contains`/`equals`/`is-empty`/`is-not-empty` filters, and one deterministic case-insensitive text sort with source-record tie-breaking.
- New public names use `@itharbors/kit-csv`, `@itharbors/csv-core`, `@itharbors/csv-explorer`, `@itharbors/csv-data`, and `@itharbors/csv-contracts`.
- All commits use `[Feature]` followed by a concise Chinese summary without a trailing period.
