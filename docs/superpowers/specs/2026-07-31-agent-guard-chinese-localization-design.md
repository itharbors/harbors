# Agent Guard 中文化设计

## 目标

将 Agent Guard 的用户可见界面完整翻译为简体中文，使流量状态、告警处置和策略阈值无需英文理解即可使用，同时保留准确的技术信息和既有视觉层级。

## 范围

中文化内容包括：

- 页面标题、副标题、监控状态、流量指标与采样说明；
- 空状态、加载状态、失败状态和重试入口；
- 事件列表、告警标记、处置按钮和保留数量；
- 策略说明、阈值字段、保存按钮和隐私边界说明；
- 屏幕阅读器状态文本及面板 HTML 的语言声明。

以下内容保持原样：`Agent Guard`、`Claude`、`Codex`、域名、供应商名、规则 ID、错误码，以及 `MiB`、`KiB`、`B/min` 等技术单位。后台返回的未知原始错误保留诊断文本，产品内置的加载和失败提示使用中文。

桌面通知不在本次界面中文化范围内；它属于后台通知通道，可在后续统一通知体验时单独处理。

## 实现方式

第一版采用面板内单语言中文文案，不引入语言切换或完整 i18n 框架。中文化只修改 Agent Guard 面板的展示层和 HTML 语言声明，不改变监控采样、流量归因、策略协议、拦截行为或存储格式。

动态状态通过现有枚举映射为中文：保护状态、置信度、事件标记和计数说明都在展示层完成转换。异常记录继续显示原始规则 ID、Agent 名称和域名，避免翻译影响排障。

## 错误处理

产品生成的加载、不可用、命令失败和重试文案使用中文。后台抛出的未知错误不做模糊机器翻译；界面保留原始诊断，以免丢失可操作信息。

## 测试与验收

先在真实面板渲染测试中加入中文文案断言，确认测试因现有英文界面失败，再替换生产文案。

验收条件：

- 正常流量、无流量、告警事件、加载和失败状态中的产品文案均为简体中文；
- 技术标识、域名和计量单位未被翻译；
- Agent Guard 完整测试通过，面板插件构建成功；
- 开发版 Electron 窗口热刷新后，中文文案无明显溢出、裁切或层级错乱。
