# Kit Manager 横向列表与历史版本设计

## 目标

把 Kit Manager 的竖向卡片网格改成便于扫描的横向资源列表，并补齐安装进行态与全部本地历史版本切换能力。改动只涉及 Manager 的公开投影与 Renderer，不扩大 preload/IPC 权限，也不改变已经完成的 Framework 热更新事务。

## 列表结构

Stable 与 Preview 分区继续保留，每个频道中的一个 Kit 占一整行：

```text
┌ 名称 / 发布者 / 简介 ┬ 频道 / 最新版本 / 权限 ┬ 已安装版本 ▼ ┬ 状态 ┬ 操作 ┐
└──────────────────────┴────────────────────────┴───────────────┴──────┴──────┘
```

桌面宽度下使用四个信息区域：身份、当前频道版本、已安装版本、操作。状态标签与频道标签放在各自信息区，不再占据独立卡片顶栏。列表使用细分隔线和左侧频道色条表达资源清单感，保留现有海港控制台配色、DIN/Avenir/等宽字体与方角按钮。

窗口较窄时，一行按身份、版本、操作顺序折成两到三行，但每个 Kit 仍是一个完整列表项。按钮保持可见键盘焦点，权限标签允许换行，长版本号不能挤出容器。

## 安装进行态

用户确认安装后，目标 Kit 行立即进入 `data-operation="install"`：

- 行内显示一个带 `aria-hidden="true"` 的不确定进度圈；
- 可见文字为 `正在下载并验证…`，全局状态区同步显示 Kit 名称和版本；
- 目标行及其他操作控件在 Promise 完成前禁用；
- 成功后刷新投影并显示 `已安装并启用…`；失败后移除进度圈、恢复控件并显示现有公共错误。

当前 IPC 只返回安装事务最终结果，没有可信的字节进度或下载/Runtime 分段事件，因此本阶段不伪造百分比。进度圈覆盖下载、证明验证、解包和 Framework 应用这一完整等待区间，但文案明确从用户最先等待的“下载并验证”开始。

`prefers-reduced-motion: reduce` 下停止旋转动画，保留静态圆环和文字状态。

## 历史版本展示与切换

Manager 已公开 `installed.versions`、`active`、`pending` 和 `badVersions`，不需要新增路径、摘要或来源字段。公开版本数组改为按规范 SemVer 从新到旧排序。

已安装 Kit 的行新增 `已安装版本` 选择器：

- 展示全部本地版本，而不是只展示 `previous`；
- 当前版本标记为 `（当前）`，异常版本标记为 `（异常）`；
- 默认选中 active；没有 active 时依次选择 pending 或最高版本；
- 选择当前版本时切换按钮禁用；选择普通历史版本时按钮为 `切换到此版本`；选择异常版本时按钮为 `重试此版本`；
- 点击后复用现有 `activate({ id, version, retryBad })`，因此任意历史版本都走同一个 Framework 热更新与失败恢复事务；
- 操作前继续提示所有 Kit 窗口会重新加载，未保存状态可能丢失。

原有 `previous` 数据和 `rollback(id)` IPC 保留兼容，但列表不再单独渲染“回滚到 previous”按钮，避免历史选择器和快捷回滚表达同一动作。删除仍只出现一次，Stable 行优先；只有 Preview 的 Kit 由 Preview 行承载。

## 状态与并发

View 维护单一进行中操作及其 Kit/channel 身份。`setBusy` 同时管理 button 与 select，避免安装期间通过版本选择器发起并发切换。重新 render 后从公开投影重建 active、异常与版本选项，不在 Renderer 保存第二份安装状态。

内置 Kit 不显示安装、版本切换或删除操作。未安装 Kit 不显示空的历史版本选择器。Registry 当前版本已经安装但不是 active 时，既可使用该行主操作立即启用，也可从历史版本选择器选择其他版本。

## 测试与验收

自动化测试覆盖：

- Stable/Preview 内容以全宽横向列表项渲染，CSS 不再使用多列卡片网格；
- 安装 Promise pending 时目标行显示进度圈、下载文案和 busy 状态，成功与失败后清理；
- 历史版本按 SemVer 新到旧展示，当前/异常标签正确；
- 当前版本不能重复切换，普通和异常历史版本分别传递正确的 `retryBad`；
- 安装、切换和删除期间 select 与 button 一起禁用；
- builtin、仅 Preview、离线已安装 Kit 和窄窗口布局保持正确。

开发过程先用 Web/JSDOM 完成布局与交互测试，最后启动 Electron，实际确认横向排版、下载进度圈和历史版本切换会触发 Framework 热更新且不重启 Manager。
