# Kit Manager 视觉优化设计

## 目标

在不改变 Kit Manager 数据、IPC 与安装/切换事务的前提下，重做界面层级、密度与操作权重。桌面窗口首屏应同时看到 Registry 状态、频道结构和至少两个 Kit；Kit 信息仍可快速扫描，历史版本、安装进度和风险权限不能被弱化。

## 视觉方向

采用“紧凑 Dock 清单”而不是通用设置页或数据表。继续使用 Harbors 的深海军蓝、钴蓝、雾蓝、橙色风险色和薄荷绿状态色，但减少背景网格、粗边框和超大文字同时出现造成的噪音。

字体继续使用系统可用的 `DIN Alternate`、`Avenir Next` 与 `SFMono-Regular`，不引入外部字体或资源。展示字体只用于标题和 Kit 名称，正文与操作回到正常字重；版本、发布者和状态使用等宽字体。

页面的识别元素是左侧 68px 的“泊位轨道”：保留深色竖栏，但移除大号倒排标题，只显示紧凑品牌字和一条橙色航道刻度。每个 Kit 行左边延续细频道色条，native-code 行使用橙色，形成轨道与泊位的关联。

## 页面结构

顶部改为紧凑控制台：左侧为 `Kit 管理`、一句说明与当前 Kit 数量；右侧为 Registry 状态、验证时间和刷新按钮。标题不超过 64px，整个首部控制在约 170px 高。

Stable 与 Preview 都使用相同的频道标题栏。空频道使用一条 64px 高的轻量提示，不再占据大面积虚线框。Preview 的展开状态仍由原生 `details` 控制。

Kit 行在宽屏分为四区：

1. 身份：名称、发布者、两行以内简介；
2. 发布：频道状态、Registry 版本、权限标签；
3. 本机：已安装版本选择器、当前/异常提示、安装进度；
4. 操作：主操作在上，删除为低权重危险操作。

行高约 124px，使用安静白色表面、1px 分隔线和极轻阴影。980px 以下折成两列，680px 以下折成一列。长版本号省略但保留完整选项值，权限标签可换行。

## 操作与状态

当前版本仍保留禁用的切换按钮，但收紧高度与颜色，不再成为视觉焦点。选中其他版本后按钮恢复钴蓝主操作；删除使用透明背景和偏红文字。安装期间在本机区显示 14px 圈和“正在下载并验证…”，全局操作消息仍作为粘性状态提示。

键盘焦点使用橙色外圈，禁用态保持足够文字对比度；`prefers-reduced-motion` 下停止旋转和位移动画。

## 验收

- 1440×900 首屏看到页面控制台、Stable 状态和至少两个 Preview Kit；
- 1100px 窗口不出现横向滚动或操作裁切；
- 620px 宽度按身份、发布、本机、操作顺序单列；
- 当前、异常、native-code 与安装中状态一眼可区分；
- 现有安装、版本切换、删除和安全边界测试不变；
- 先提供浏览器高保真预览，经用户确认后落到正式 CSS/DOM，并以 Electron 原生窗口最终验收。
