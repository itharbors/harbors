# CSV Kit

CSV Kit 是 Harbors 内置的中文只读表格检查器。它通过浏览器原生文件选择器打开本地 `.csv`、`.tsv` 与 `.txt` 文件，
建立会话级临时索引，并通过数据和结构两个标签页提供分页浏览、搜索、筛选、排序、字段统计与安全导出。

```bash
npm run dev -- --kit ./kits/csv
```

## Local lifecycle

```bash
npm ci --prefix kits/csv
npm run build --prefix kits/csv
npm run test --prefix kits/csv
```

本 Kit 未声明独立 smoke 脚本，以仓库目标 Kit 的完整检查验收。

## Permissions

`filesystem`、`native-code`。

## Platform

仅支持 macOS arm64，Node ABI 127。

## Ownership boundary

CSV 功能实现、原生依赖与测试均由本目录拥有。

## 格式与解析配置

- Kit 不再维护目录浏览或手填路径入口。桌面版会把原生选择结果解析为运行 Harbors 的本机绝对路径；Web 无法取得该路径时会提示此功能只能读取本机文件，不会上传或复制文件内容。
- core 收到路径后仍会独立验证普通文件、拒绝符号链接，并执行下述大小和解析边界；Panel 不把选择结果视为可信输入。
- 支持 UTF-8（含 BOM）和 GB18030。自动模式仅在 UTF-8 BOM 存在时直接确定编码；否则严格尝试
  UTF-8，失败后建议 GB18030。打开前始终可以手动覆盖编码。
- 支持逗号、制表符和分号分隔符，引用符固定为双引号；支持转义双引号、字段内逗号、字段内换行、
  LF 与 CRLF。打开前可以覆盖自动建议的分隔符与“首行是字段名”。
- 空表头显示为“未命名列 N”，重复表头附加显示序号。源表头和单元格始终按文本保存，因此
  `0007` 等前导零不会被改写。
- 宽度不一致的记录会补为空字符串或生成额外列，并显示不规则记录警告；警告不会静默丢弃数据。

## 只读与查询语义

CSV Kit 只读打开源文件，不提供原地新增、修改或删除，也不修改源文件。索引仅位于操作系统临时目录，
关闭文件、切换文件、卸载插件或结束 Session 时会清理。

数据页支持 25、50、100 或 250 行分页。快速搜索扫描全部字段；字段筛选支持 `contains`、`equals`、
`is-empty` 和 `is-not-empty`。搜索、文本筛选与排序不区分大小写，排序值相同时按源记录号稳定排序。
所有值都按原始文本处理，不推断数字或日期类型。

## 导出安全

“导出当前结果”按当前搜索、筛选和排序顺序写入新的 UTF-8 BOM CSV。导出使用流式分页读取，正确转义
逗号、双引号和换行；目标路径已存在或与源文件相同时会拒绝操作，因此不会覆盖源文件或既有文件。
导出可取消，失败或取消会移除本次创建的不完整目标。

## 资源边界

- 源文件默认最大 2 GiB；
- 单条记录最多 10,000 列；
- 单条记录解码后最大 16 MiB；
- 单个字段解码后最大 16 MiB；
- 建索引前检查临时目录可用空间；解析和导出都采用流式处理，不把完整文件发送到浏览器或保存在数组中。

无法解码、未闭合引号、非法路径、符号链接、空间不足与资源超限会显示明确错误。切换到新文件失败时，
此前成功打开的文件仍可浏览。
